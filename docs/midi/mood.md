# MOOD (MKI, 2019)

Default channel 2. Save: only PC while holding both footswitches.

| CC | Parameter | Values |
|---|---|---|
| 14 | Time | 0–127 |
| 15 | Mix | 0–127 |
| 16 | Length | 0–127 |
| 17 | Wet modify | 0–127 |
| 18 | Clock | 0–127 |
| 19 | Loop modify | 0–127 |
| 21 | Wet program toggle | 1 left · 2 middle · 3 right |
| 22 | Routing toggle | 1 · 2 · 3 |
| 23 | Loop program toggle | 1 · 2 · 3 |
| 100 | Expression | 0–127 |
| 102 | Bypass | 127 engage last saved bypass state, 0 bypass |
| 103 | Bypass state | 127 both on · 85 wet on, loop bypassed · 45 loop on, wet bypassed · 0 both bypassed |

Not documented: CC20, MIDI clock, tap, dip switches.
