# CXM 1978 (Automatone)

Default channel 2. Source: CXM-1978_MIDI-Manual and CXM-1978_Manual (Chase Bliss × Meris, 2020).

**Automatone format:** 5-pin DIN MIDI IN and THRU (no TRS adapter needed). Six motorized faders, five arcade
buttons with a tri-colour LED, a 7-segment display, BANK and ACTIVE LEDs. **No live state and no preset
toggle:** 30 presets in 3 banks × 10, recalled with **PC 0–29** (PC 4 = bank 1 preset 4, PC 17 = bank 2 preset 7,
PC 20 = bank 3 preset 0) and saved with **CC 27 = slot (0–29)**. On the pedal: PRESET footswitch = next preset,
hold = next bank; hold BYPASS = save to the current preset.

**Channel change:** hold both footswitches at power-up, release when the display lights, then send a *Program
Change* on the new channel (may need repeating).

## Faders (0 = full down, 127 = full up)
| CC | Fader | Notes |
|---|---|---|
| 14 | BASS | decay time below the crossover |
| 15 | MIDS | decay time above the crossover |
| 16 | CROSS | crossover 0 Hz – 1700 Hz, ~362 Hz at the centre |
| 17 | TREBLE | high-frequency absorption |
| 18 | MIX | analog wet / dry balance |
| 19 | PRE-DLY | pre-delay; range follows CLOCK: HiFi 42 ms, Standard 168 ms, LoFi up to 1.7 s (and sets the sample rate) |

## Arcade buttons — only values 1, 2 and 3 are documented
| CC | Button | 1 (LED off) | 2 (blue) | 3 (red) |
|---|---|---|---|---|
| 22 | JUMP | Off | preset 0 | preset 5 |
| 23 | TYPE | Room | Plate | Hall |
| 24 | DIFFUSION | Low | Med | High |
| 25 | TANK MOD | Low | Med | High |
| 26 | CLOCK | HiFi (48 kHz / 32-bit) | Standard (24 kHz / 16-bit) | LoFi (48–2.4 kHz / 16-bit) |

What values 0 or 4–127 do on these CCs is not documented — the editor never sends them.

## Aux performance functions (the Meris Preset Switch over MIDI)
| CC | Function | Values |
|---|---|---|
| 28 | AUX PERF SWITCH 1 | any value: faders to the expression heel position, again = back to the preset |
| 29 | AUX PERF SWITCH 2 | any value: faders to the expression toe position, again = back to the preset |
| 30 | AUX PERF SWITCH 3 | any value: buffer clear (cuts the reverb tail) |
| 31 | AUX PERF SWITCH 4 | 0 = sustain lock on, 1 (or more) = off (fades out with the decay settings) |

The editor sends 127 for the "any value" triggers. Sustain lock is a performance state and is never replayed
from presets or on sync.

## Other
| CC | Function | Values |
|---|---|---|
| 27 | PRESET SAVING | 0–29 = slot to save the current settings into |
| 100 | EXPRESSION over MIDI | 0 heel … 127 toe, through the per-preset expression mapping (not sent by the editor) |
| 101 | EOM UNLOCK | any value unlocks "EOM lock"; semantics undocumented (not sent by the editor) |
| 102 | BYPASS / ENGAGE | 0 bypassed, 1 (or more) engaged |

No tap tempo, no MIDI clock. Balanced / unbalanced I/O, dry kill and trails are set on the pedal only. The pedal
does not transmit its state.
