# Warped Vinyl MKII

Default channel **5**. Save: only PC while holding TAP + BYPASS (no save CC).

| CC | Parameter | Values |
|---|---|---|
| 14 | Tone | 0–127 |
| 15 | Volume | 0–127 |
| 16 | Mix | 0–127 |
| 17 | RPM | 0–127 |
| 18 | Depth | 0–127 |
| 19 | Warp | 0–127 |
| 20 | Ramp | 0–127 |
| 21 | MIDI note divisions | 0 whole · 1 half · 2 quarter triplet · 3 quarter · 4 eighth · 5 sixteenth |
| 51 | MIDI clock ignore | 0 ignore, 127 listen (default: listen) |
| 93 | Tap switch | any value = tap |
| 100 | Expression | 0–127 |
| 102 | Bypass | 127 engage, 0 bypass; 127 while engaged resets ramping |

MIDI clock: 24 PPQN; the tap-division toggle selects notes per vibrato period.

**Not MIDI-controllable per manual:** the three toggles (tap division 1/2/4 · 3/6/8, left and right wave shape) and all dip switches.
